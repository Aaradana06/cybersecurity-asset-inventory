# Cybersecurity Asset Inventory System

## About the Project

The Cybersecurity Asset Inventory System is a Python-based mini project
designed to manage an organization's IT assets and track their security
risk and status.

## Features

- Add Asset
- Search Asset
- Update Asset
- Delete Asset
- Display All Assets
- Risk Summary

## Asset Information

Each asset contains:

- Asset ID
- Asset Name
- Asset Type
- IP Address
- Operating System
- Department
- Risk Level
- Security Status

## Asset Types

- Workstation
- Server
- Router
- Switch
- Application

## Risk Levels

- Low
- Medium
- High
- Critical

## Security Status

- Secure
- Warning
- Vulnerable

## Technology Used

- Python
- GitHub
